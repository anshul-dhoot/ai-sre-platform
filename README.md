\# AI-SRE Platform



A production-shaped AI SRE platform for investigating and diagnosing

failures in data-intensive distributed systems.



\## Goal



Build a hands-on engineering project covering:



\- Event-driven architecture

\- Kafka

\- Streaming and batch processing

\- Data storage and querying

\- Data quality

\- Observability

\- Incident investigation

\- AI agents and tool calling

\- Production deployment

\- CI/CD



The platform will run locally on a resource-constrained laptop during

development and will later be deployed using production-oriented

architecture.
